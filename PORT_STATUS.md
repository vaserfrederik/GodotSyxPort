# Port status

## Текущий этап

Восстановлен полностью C#-маршрут main menu → generation/race/region selection →
settlement → world overview. Выбранный мировой регион теперь задаёт профиль
генерации поселения и расу первых жителей. Save v36 сохраняет сессию, точный рельеф
стратегического мира, координаты столицы, ключевое состояние поселения, крышу, мебельные footprint/роли и построенные полы;
формат также сохраняет распределение эмиссаров. `Continue` восстанавливает этот маршрут.
