# Checkpoint A73 — stockpile policies

Дата: 2026-09-15

## Готово

- Stockpile принимает ресурс только при выделенном ему ящике.
- Число allocations ограничено фактическим количеством crate furniture.
- Для каждого ресурса задаётся индивидуальный per-crate limit.
- Нельзя уменьшить allocation или limit ниже уже занятого и зарезервированного объёма.
- `fetching` управляет сбором loose resources; `priority` определяет выбор склада.
- Настройки доступны в общей панели политики комнаты.
- Политики входят только в текущий save; миграции старых форматов не добавлялись.
- Исходная вместимость по upgrade остаётся 80/300/500 единиц на ящик.
- Settlement map остаётся 768×768.
