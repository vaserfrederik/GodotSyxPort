# Первый локальный запуск

## Требования

- Godot 4.x **.NET** (обычная версия без C# не подходит).
- Установленный .NET SDK, поддерживаемый выбранной версией Godot.

## Запуск

1. Полностью распакуйте архив в отдельную папку.
2. Откройте Godot Project Manager.
3. Нажмите **Import** и выберите `project.godot`.
4. Дождитесь импорта и компиляции C#.
5. Запустите главную сцену клавишей F6/F5. Проект уже указывает `Main.tscn` как стартовую.

Первый запуск использует процедурные заглушки: клетки и стены отображаются цветными
`BoxMesh`, жители — `CapsuleMesh`, карты и панели — стандартными Godot Controls.
Модели, текстуры и исходные sprite sheets для этого checkpoint не требуются.

## Что проверить

- открывается окно 1600×900 и появляется главное меню;
- `Новая игра` открывает глобальную карту, выбор расы и региона;
- после выбора пригодного региона кнопка основания запускает 3D-поселение;
- раса первых жителей и параметры местности соответствуют сделанному выбору;
- видны жители-заглушки, компактный верхний HUD и нижняя панель строительства;
- центр карты свободен: крупные окна при старте закрыты и открываются по одной кнопками нижней панели;
- кнопки времени переключают скорость;
- `F2` открывает администрацию;
- `F3` открывает стратегическую карту;
- `M` открывает карту поселения;
- `В мир` возвращает на глобальную карту, а `Вернуться в поселение` продолжает симуляцию;
- после `Ctrl+S` и возврата в главное меню кнопка `Продолжить` восстанавливает ту же сессию;
- в Output/Debugger нет фатального исключения во время `_Ready()`.
- выберите комнату через `I`, затем нажмите `Delete`: её jobs отменяются, мебель/зоны
  удаляются, а складские остатки выпадают loose resources;

## Первая постройка

1. Нажмите `Стена` или `Дорога`, затем протяните мышью по свободной карте.
2. Для здания нажмите `Комната`, выберите исходный тип в открывшемся каталоге — каталог закроется сам.
3. Протяните площадь на карте, добавьте при необходимости `Проём` и `Мебель`.
4. Нажмите `Готово` для передачи черновика строителям. `Отмена` удаляет выбранную планировку.

`Esc` закрывает любое крупное окно. Одновременно открывается только одно окно, поэтому
скрытые панели больше не перехватывают клики по карте.

Если компиляция или запуск остановятся, сохраните полный текст первой ошибки и несколько
следующих связанных ошибок. Исправлять визуальный вид на этом checkpoint не требуется.

## Проверенное состояние архива

Статическая проверка: `python3 Tools/verify_port.py` → `PORT_STATIC_VERIFICATION_OK`.
Среда подготовки архива не содержит Godot/.NET, поэтому настоящая компиляция и запуск
должны быть выполнены локально.
