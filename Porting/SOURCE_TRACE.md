# Source trace

This file records the original Java behavior used for each semantic port. It
separates verified mechanics from Godot-specific implementation choices.

### Configuration boundary

The supplied original data provides `RATE: 0.5`, 48 seconds/hour and 24
hours/day. `HumanoidResource` specifies 16 need updates per day and
`StatsNeeds.update16` increments hunger with probability `RATE` on each update.
The port therefore checks every 72 game seconds with probability 0.5 and gives
each citizen the source-equivalent random initial phase to avoid synchronized
update spikes. Per-race modifiers are not connected yet; the base cadence, thresholds, priority
ordering, food quantity, eating effect and eating duration are source-verified.
