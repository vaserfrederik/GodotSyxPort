# Контрольная точка A82 — горы, сведения места и язык

Дата: 2026-09-16

## Исправлено

- Рендер гор больше не копирует один участок `Mountain.png` на каждую клетку.
- Перенесена структура `ComposerSources.house2` из `WorldMountain.java`: 16 масок углового соединения, исходные смещения внутри блока 96×64 и выбор набора по высоте горы.
- Экран создания мира и внутриигровой стратегический обзор используют один общий рендерер территории.
- Окно сведений о выбранном месте вызывается движением мыши, следует за курсором и меняет сторону возле границ экрана.
- Добавлены два явно поддерживаемых языка интерфейса: русский (`ru`) и английский (`en`).
- При первом запуске всегда выбирается русский; выбор пользователя сохраняется в `user://settings.cfg`.
- Для шести игровых рас добавлены русские названия, описания, сложность, достоинства и недостатки.

## Проверка

- Статическая проверка выполняется командой `python3 Tools/verify_port.py`.
- Фактический импорт атласов и визуальный результат нужно проверить в Godot 4 .NET на целевом ПК.
